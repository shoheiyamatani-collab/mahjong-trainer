# 差し替え音声

任意の MP3 または WAV ファイルを次の場所へ置くと、動画生成時に自動使用します。

- `se/quiz-question.mp3` — 出題SE（冒頭1秒に収まるよう自動トリミング）
- `se/clock-second-hand-loop.mp3` — 回答時間用の8秒タイマーSE
- `se/quiz-correct.mp3` — 正解SE（最大1.2秒）
- `jongfolio-logo.wav` — 終盤の「雀フォリオ！」サウンドロゴ

SEがない場合は、ジェネレーターが権利上安全な単純波形を出力フォルダ内へ生成します。サウンドロゴは未配置なら省略します。
