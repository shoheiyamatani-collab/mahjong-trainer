# 動画紹介・Mリーグの独自教材補強

## 対象と作業範囲

既存の動画・外部リンク中心のページに、動画を再生しなくても確認できる説明と、既存ロジックで検証した比較例を追加した。
記事数や文字数を増やすことではなく、見出しで約束している内容を本文で説明できることを優先した。

- 作業開始時は変更なし。リモートの `ad0a75e4`（Mリーグのハイライト更新）をfast-forwardで取り込んだ。
- 対象は既存4ページ。新規URL、依存パッケージ、広告枠は追加していない。
- 計算・問題生成エンジン、既存metadata、canonical、公開・noindex設定、制作済み30記事は変更していない。
- 本番デプロイ・Git push・AdSense再申請・管理画面操作はしていない。

## 具体例の検証

1. **対子とブロックの比較**
   - 手牌: `12388m45699p67s東東`、14枚、同一牌4枚以下。
   - `analyzeDiscards`で9筒切りは1シャンテン・4種12枚、6索切りは1シャンテン・3種6枚。
   - 受け入れの内訳も本文に記載し、同じ14枚をチェッカーへ渡す。
   - 最善打の唯一の正解、和了率、期待値、役牌の打点価値まで判定したとはしない。
2. **役なしのテンパイ**
   - 手牌: `234567m678p34s白白`、13枚。2索・5索待ち。
   - 両方のアガリ牌について、既存の役判定が役なしロンを拒否し、リーチありならリーチ、ツモなら門前清自摸和となることを検証。
   - 初期候補は2索で三色同順になることをテストが検出したため、未検証のまま公開せず牌姿を修正した。
3. **スジの反例**
   - 手牌: `22789m23455p678s`、13枚。2萬・5筒のシャンポン待ち。
   - 5萬の捨て牌と両立し、2萬でロンできることを検証。
   - この例から実際の放銃率や、他家の手牌を推定したとはしない。
4. **点棒移動**
   - 東32,000・南28,500・西22,000・北17,500。自分は南、親は東、0本場・供託なし。
   - 既存の `direct-hit` プリセットとの一致をテスト。
   - 2翻30符の支払いは `calculateScore` で検証。全例で点棒合計100,000点を維持。
   - 東から2,000点ロン: 自分30,500・東30,000、トップ逆転。
   - 西から2,000点ロン: 自分30,500・東32,000、未達。
   - 500／1,000点ツモ: 自分30,500・東31,000、未達。
   - この表は最低必要点の表ではない。終局・連荘、同点規定、チームのシーズン成績とは区別。
5. **四暗刻のアガリ方**
   - 手牌: `222m555p777s白白中中`、13枚。白・中待ち。
   - 中ロンは三暗刻・対々和・役牌、中ツモは四暗刻と、既存の役判定で確認。
   - 表示画像の13枚・牌名も、実際に検証する手牌データとの一致をテスト。

## 動作・表示確認

- 4ページを375 / 768 / 1440pxで実ブラウザ確認。ページ全体の横はみ出し、比較表の欠け、牌画像の破損なし。
- 動画記事の13・14枚は一列を維持。375pxでは22pxの牌幅を保ち、14枚も局所横スクロールなしで表示。
- より狭い画面では、牌を極端に縮めず図だけ局所横スクロールできる。
- 記事のリンクからチェッカーへ14枚が渡り、実画面でも9筒12枚／6索6枚を確認。
- Mリーグのリンクからオーラス計算へ移動し、同じ4人の持ち点・自分の席・親・目標・本場・供託が入力されることを確認。計算ボタンで直撃2,000点の条件を確認。
- 確認用のYouTubeタブは、音を止めてほしいという依頼後に2つとも閉じた。その後は動画を再生せずに作業した。

## 残る課題

- 今回改善した動画は2記事であり、全68記事の全編照合が終わったわけではない。特にプロの実戦解説や鳴き読みの局面根拠は引き続き確認が必要。
- Mリーグの動画・選手・プロフィールの権利や全掲載メモを、一括で確認済みにはしていない。
- Mリーグ公式ルールの今回の取得はメンテナンス画面へ遷移したため、最新競技規定の再取得は未完了。一般的な役・点棒の教材を、最新のMリーグ固有規定の確認と混同しない。
- noindexは検索掲載の設定で、AdSenseの審査対象から外れる保証ではない。既存設定の変更、大量削除、未確認ページの一括公開停止は行っていない。
- AdSense管理画面での所有権確認の認識、再申請可能な状態は未確認。再申請そのものも行っていない。
- この変更はローカルのみ。本番へ反映するには別途デプロイが必要。
