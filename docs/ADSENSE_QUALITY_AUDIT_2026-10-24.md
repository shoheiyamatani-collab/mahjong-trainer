## 確認範囲と前提

- `main` の `11663a2b` を基準に、公開サイト・既存コード・静的HTMLを調査。
- サイトマップの81URLを本文・牌図・重複段落の観点で確認。文字数は調査の手掛かりであり、承認基準や最低文字数ではない。
- ユーザー提供の管理画面スクリーンショット `5354.jpg`・`5355.jpg` で、今回も「有用性の低いコンテンツ」と表示されていることを確認。管理画面を直接操作した結果ではない。具体的にどのURLが原因なのかは表示されていないため、個別ページを不承認の確定原因とは扱わない。
- スクリーンショットでは所有権確認は完了。審査リクエスト回数が上限に達したため、再申請は2026年10月30日以降と案内されている。この日付は承認予定日でも自動再申請日でもない。再申請時は管理画面の最新表示を確認する。
- noindexは検索掲載の方針。AdSense審査からの除外を保証するものではなく、審査員とユーザーに違う本文を見せる実装も行わない。

## 確認できた問題と今回の修正

| 問題 | 対応 |
| --- | --- |
| 両アプリの共通レイアウトで全ページに広告配信スクリプトを読み込んでいた | 無条件の配信スクリプトを停止。Metadata APIの所有権確認メタタグと既存ads.txtを維持 |
| リーチ記事の13枚を五筒待ちだけとしていた | 二筒・五筒待ちへ訂正。手牌のみの理論枚数は計6枚。既存計算処理で両方の待ちを検証 |
| リーチ・タンヤオ・七対子の記事が成立条件の短い紹介に偏っていた | 鳴きの可否、具体的な点数と条件、誤りやすい点、確認問題、実在する練習へのリンク、公式ルール確認先を追加 |
| 良形率の説明が両面やアガりやすさと混同しやすかった | 5枚・9枚の判定基準、理論枚数での重み付け、30/54=約56%、18/54=約33%を明記。14枚を入力して再現する導線を追加 |
| 計算の確定値と局面判断の推定値の区別が運営情報では不明瞭 | `/about#calculation-policy` に説明と限界、訂正の連絡方法を掲載。ツールHELPからもリンク |
| 審査モードでもトップページ下部に動画・Mリーグへの目立つ直リンクが残っていた | 牌効率の記事、牌理チェッカーHELP、点数計算HELPへの内部導線に変更。通常モードの動画・Mリーグ表示は維持 |
| トップページの検索向け説明が審査モードの中心コンテンツとずれていた | 審査モードでは牌姿つき解説・独自練習・解析/点数計算ツールを説明し、通常モードのmetadataは従来のまま |

計算・判定・問題生成コードは変更せず、既存の牌図・記事表示を再利用。既存URL、タイトル、description、canonical、構造化データ、robots方針を維持している。検索一覧のプレビューは新しい牌図位置へ合わせ、見た目とリンク先を維持した。

## 再申請前に残る確認

1. 不承認理由は「有用性の低いコンテンツ」とスクリーンショットで確認済み。Googleは原因URLや合格点を示していない。独自価値・正確性・構成を改善し、2026年10月30日以降に再申請できるか最新表示を確認する。
2. 今回の変更はローカル段階。公開後、メタタグまたはads.txt方式で所有権確認が認識されるか管理画面で確認する。再申請は別途行う。
3. 審査モードでは第三者動画・Mリーグの生成済みページを公開出力から外す実装を追加した。ソースとデータは保持し、モード解除後に元URLで再生成できる。審査モードを解除しても各ページは `needs-improvement` のため自動で検索復帰しない。権利、出典、実質的な独自価値を継続確認し、ready化または統合を判断する。
4. 運営者の紹介に加えられる実体験・制作背景は本人確認が必要。実在しない資格・実績・プロ監修は掲載しない。問い合わせの実受信も別途確認が必要。
5. 自動テストは計算例の確認であり、全記事の人による校閲や承認の保証ではない。まだ薄い記事も、長文化を目的にせず、読者が再現できる比較・判断例から順に改善する。

広告コードの整理は、所有権確認と広告配信を分離するための修正であり、不承認理由を解消する主対策とは断定しない。現時点の所有権確認が失敗していた、とも解釈しない。文字数やアクセス数を増やすだけで承認されるという判断も行わない。

## 審査モードでの一時非公開

`publicationPolicy.json` を公開状態の唯一のルートグループ設定として、`ADSENSE_REVIEW_MODE=true` のビルドでは生成された `/videos/**` と `/mleague/**` を `apps/web/out` から除外する。削除対象は再生成可能なビルド成果物だけで、ソースやデータセットには触れない。トップナビ、メニュー、フッター、トップの関連導線、サイトマップも同じ状態に揃え、静的検証では非公開ページの残存と内部リンクを検出する。Googlebot全体をrobots.txtでブロックしない。

通常モードで再ビルドすればURLを再生成する。ただし `needs-improvement` は維持されるため、noindexとサイトマップ除外は続く。これは運用上の一時停止であり、AdSense審査の結果を保証しない。また公開サイトでの直接アクセスは審査中404になるため、利用者向けに動画・Mリーグを維持する必要がある場合は、この公開範囲判断を再検討する。
